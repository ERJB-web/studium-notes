# Notes StudiUM

Un bouton à ajouter dans les favoris de son navigateur pour remplir plus vite les notes sur StudiUM, voir les statistiques de la classe et passer par Excel (colonnes Nom, Prénom, Note).

Il fonctionne sur StudiUM (studium.(université concernée), par exemple studium.umontreal.ca).

**Installation :** https://erjb-web.github.io/studium-notes/ (glisser le bouton dans les favoris, ou télécharger le fichier).

- Outil en HTML, CSS et JavaScript. Une fois installé, il fonctionne entièrement dans le navigateur : il ne charge rien depuis ce site, ne communique avec aucun serveur en dehors de StudiUM et ne se met jamais à jour tout seul.
- L'outil ne garde rien et n'envoie rien. À chaque ouverture, il lit la page StudiUM affichée à l'écran : les noms et les notes viennent de cette page.
- Ce qu'on saisit est effacé quand on ferme l'outil ou la page.
- Aucune IA ne traite les données.
- Les notes s'inscrivent pendant la frappe. L'outil affiche chaque note changée (avant, après) et signale en bleu les noms approchants. « Annuler les modifications » remet les notes d'origine.
- Rien n'est enregistré dans StudiUM tant qu'on ne clique pas sur « Enregistrer ». Il vous appartient de vérifier l'exactitude des notes inscrites avant d'enregistrer.
- Pour une nouvelle version, revenez sur la page et téléchargez de nouveau le fichier.
- Usage non commercial uniquement.

<sub>NB : Codage assisté par IA utilisé uniquement lors de la conception. Le code est accessible publiquement.<br>Un audit humain n'a révélé aucune transmission de données.</sub>
